# Compression Reference Data

Raw CSVs and DPD-formatted files for compression experiments.

Expected DPD files:
- `compression_data_2.1um.dat`
- `compression_data_2.9um.dat`
- `compression_data_3.0um.dat`

Format: `Displacement  Force` (DPD units).

Plotting: `plot_reference_data.py` (run via SLURM).
