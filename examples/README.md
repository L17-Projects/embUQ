# Example config bundle

This directory provides a small public example bundle built from the canonical production configs already shipped in the repository.

## Files

- `configs/compression_full.yaml`
- `configs/indentation_full.yaml`
- `configs/compression_reduced.yaml`
- `configs/indentation_reduced.yaml`
- `reports/workstation_acceptance_report.example.json`

## Purpose

These files are not new workflow definitions. They are convenience copies intended for:

- quick first-time inspection
- small local edits without touching the canonical production configs
- release notes and docs references
- machine-readable report examples for manual validation records

For the authoritative maintained versions, see:

- `inference/configs/production/`
- `reduced/configs/production/`
